Entry for the make.fun bounty **Your Week in One Line** (`u-boge-your-week-in-one-line-d1c14ced`).

`main.ts` (Node 22+) writes a single line summing up the week — 81 entries shipped,
zero dollars won, and the sharpest line of the week is the line itself — to
`/output/entry.txt`.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
